# AI & Data Journey

A personal learning journey into **Python, Data Analysis, Artificial Intelligence, and Machine Learning**.

This repository contains my notes, exercises, resources, experiments, and projects as I build my understanding step by step.

The goal isn't to learn everything at once. It's to understand the fundamentals, build things with them, and gradually move toward AI.

The main Python tools used for working with data.

# Learning Method

I'm following a simple cycle:

```text
Learn
  ↓
Understand
  ↓
Practice
  ↓
Build
  ↓
Reflect
  ↓
Move on
```

I don't want to spend months trying to completely master one technology before touching the next one.

The goal is to learn **enough to build**, then deepen my understanding through practice and projects.
