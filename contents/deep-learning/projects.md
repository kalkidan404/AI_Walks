# Project 1: Image Classification

### Objective

Build an image classification model using PyTorch that can recognize and classify clothing images into different categories.

### Dataset

Fashion-MNIST — a dataset containing 70,000 grayscale images across 10 clothing categories.

### What You Will Build

Develop two neural network architectures and compare their performance:

1. **Feedforward Neural Network (FNN):** Build a basic neural network that classifies images using flattened pixel values.
2. **Convolutional Neural Network (CNN):** Build a CNN that learns spatial patterns and visual features from images.

### What You Will Learn

- Loading and exploring image datasets.
- Understanding tensors and image dimensions.
- Data preprocessing and normalization.
- Building neural networks with PyTorch.
- Understanding forward propagation and backpropagation.
- Training and validating models.
- Understanding convolutional and pooling layers.
- Comparing FNN and CNN architectures.
- Evaluating classification performance using accuracy, loss, and confusion matrices.

### Final Goal

Understand how neural networks learn visual patterns and why CNNs are particularly effective for image classification.

# Project 2: Text Classification

### Objective

Build a sentiment classification model using PyTorch that can determine whether a movie review expresses a positive or negative opinion.

### Dataset

IMDb Movie Reviews — a dataset containing 50,000 labeled movie reviews.

### What You Will Build

Develop and compare three neural network approaches:

1. **Embedding + Mean Pooling:** Build a baseline model that converts words into embeddings and averages their representations before classification.
2. **LSTM:** Build a recurrent neural network that processes text sequentially and learns information from word order.
3. **Improved LSTM:** Introduce dropout regularization to address overfitting and improve generalization.

### What You Will Learn

- Text cleaning and preprocessing.
- Tokenization and vocabulary construction.
- Word-to-index encoding.
- Padding and truncating sequences.
- Understanding word embeddings.
- Building neural networks for text classification.
- Understanding mean pooling and LSTM architectures.
- Training and validating models with PyTorch.
- Understanding overfitting and regularization.
- Evaluating models using accuracy, precision, recall, F1-score, and confusion matrices.

### Final Goal

Understand how neural networks process language, learn representations of words, and use those representations to perform sentiment classification.
